# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue. Email the maintainers (see the repository owner's profile) with a description, reproduction steps and impact. We aim to acknowledge reports within 3 working days and to fix critical issues within 14 days.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |
